Turn a live Geomacro risk state into a proof anyone can verify on Arc.

Geomacro produces machine-readable geopolitical and macro risk intelligence. This page takes one current state, creates a deterministic proof in your browser, anchors that proof on Arc mainnet, and lets anyone verify the transaction later without trusting this page.

01Generate

Load a current Geomacro intelligence state and compute its SHA-256 proof.

02Anchor

Write the proof record to Arc mainnet with a wallet-signed transaction.

03Verify

Paste any proof transaction and independently recompute what was anchored.

Important: anchoring is a real Arc mainnet transaction and uses a small amount of USDC for gas. Geomacro never receives or stores your private key.

What goes onchain?

The transaction calldata contains only a compact public proof record:

GEOMACRO_ARC_MAINNET_V2|<country>|<state_version>|<as_of>|<freshness>|<sha256_proof>

The proof hash is computed from schema, country, state version, as-of timestamp and freshness. The transaction sends zero value to the connected wallet itself, so the only cost is Arc gas. No personal data or secrets are included.
